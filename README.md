# 你的手机没有原子钟 —— GPS 定位模拟

## 怎么跑
直接双击 `index.html` 就能打开，不用装任何东西。
测试求解器：`node test-solver.js`

## 文件结构
| 文件 | 干嘛的 |
|---|---|
| `solver.js` | **核心机制**：生成伪距、Gauss-Newton 迭代求位置和时钟误差。面试主要讲这个。 |
| `app.js` | 画图、拖拽、滑块。不含数学。 |
| `index.html` | 页面布局和说明文字 |
| `test-solver.js` | 用 node 验证求解器算得对 |

## 核心想法（一句话）
接收机的钟不准，所以每颗卫星的距离都被**同一个量**算错了。
既然是同一个量，就可以把它当成多出来的一个未知数，和位置一起解：
平面上要 3 颗卫星，三维空间里要 4 颗。

## 单位
距离 km，时间 μs，光速 C ≈ 0.3 km/μs（1 μs 的误差 ≈ 300 m）。
地图是玩具尺度（100 km 宽），真实卫星在约 2 万 km 高空。
